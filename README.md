# Aidict — AI Translator

Android Flutter translation app. Offline translation is limited to Arabic ↔ English after downloading local models. Other languages use online translation.

## Current status

**Stage 0 is not complete.** The complete Flutter source package still needs to be uploaded; this README initializes the repository but does not contain an app or an APK. After adding the source, run Flutter analysis, tests, and an Android debug build through CI. Test offline Arabic ↔ English on a real Android device in airplane mode.

## Planned features

Camera translation, screenshot OCR, two-person voice conversation, PDF/DOCX translation, audio transcription/translation, clipboard translation, bilingual dictionary, proofreading and rewriting, favorites/history, vocabulary learning and quizzes, dark mode.

Proceed stage by stage and require passing tests before advancing.
